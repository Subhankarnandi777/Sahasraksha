# Sahasraksha-Edge — ESP32 firmware (SIH26073)

The station-level Sahasraksha detector running on an ESP32 + BME280, with no uplink needed.

**Start here: [`ESP32.md`](ESP32.md)**, the full task brief: PS requirements, wiring, build, tests, energy measurement, and the numbers to report.

Quick start (PlatformIO): `pio run -t upload && pio device monitor`, then type `t` (self-test), `b` (benchmark), `r` (replay the PS 55 °C example), `x` (inject it live).
